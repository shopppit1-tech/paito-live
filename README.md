# Paito Live

Situs statis berbahasa Indonesia untuk tampilan Paito SDY. Buka `index.html` di browser atau hosting statis.

## Berkas

- `index.html` — struktur halaman dan konten.
- `styles.css` — gaya/tampilan responsif.
- `script.js` — navigasi mobile, marquee hasil, dan tabel.

## Catatan data

Nilai yang ditampilkan oleh `script.js` saat ini dibuat dari data contoh yang tertanam di berkas, bukan dari API atau sumber live. Tautan eksternal dan placeholder `#` juga masih perlu ditinjau sebelum dipakai sebagai situs produksi.
